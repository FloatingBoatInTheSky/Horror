CONFIGURAÇÕES DO SISTEMA

GUIA DE CONTROLES

[PC / TECLADO & MOUSE]

• W, A, S, D / Setas: Movimentação

• Mouse: Olhar ao redor (Clique para travar mira)

• E: Interagir com portas, itens e códigos

• F: Ligar / Desligar Lanterna

• Shift: Correr

• C / Ctrl: Agachar

• ESC: Menu de Pausa


[CELULAR / MOBILE]

• Lado Esquerdo: Joystick virtual de movimento

• Lado Direito: Arraste para mover a câmera

• Botões virtuais: [E] Interagir, [Luz] Lanterna, [Inv] Inventário, [||] Pausa


[GAMEPAD / XBOX]

• Analógico Esquerdo: Mover

• Analógico Direito: Olhar

• Botão A: Interagir

• Botão X / Y: Lanterna

• Botão B: Correr
